The Problem

Why Reproducibility Matters in Spatial Epi

Scenarios you know:

  • Rerun a spatial script → 12 package conflicts (raster vs terra)
  • Share a risk map → stakeholder asks “which climate data vintage?”
  • Return to your own code after 8 months → hardcoded paths, missing files
  • Submit to journal → reviewer can’t reproduce Figure 3 choropleth
  • Collaborate across institutions → “it works on my machine”

The Spatial Reproducibility Problem

Geospatial analyses are especially fragile:

  • Large binary files (rasters, shapefiles) can’t go in git
  • terra replaced raster; sf had breaking changes
  • Coordinate systems silently mismatched
  • Data provenance rarely documented

For policy-relevant risk maps, reproducibility is an ethical obligation — not a nice-to-have.

BLOCK 2

Locking the Environment with renv

The Spatial Package Versioning Nightmare

The timeline:

  • 2022: You build a risk model with raster 3.5
  • 2023: terra released, raster deprecated
  • 2024: Colleague installs fresh R → gets terra only → your script breaks
  • 2025: You can’t remember which CRS projection you used

renv locks the entire spatial stack:

renv::init()
install.packages(c("terra", "sf", "geodata",
                   "tidyterra", "ggplot2"))
renv::snapshot()   # writes renv.lock
# Colleague restores exact same environment:
renv::restore()

BLOCK 5

The Model: Climate-Driven Malaria Risk Index

Why Climate? Why Geospatial?

Malaria transmission is strongly climate-constrained:

  • Anopheles mosquito survives 16–34°C
  • Optimal transmission ~25°C (Mordecai et al. 2013)
  • Rainfall creates breeding sites (but too much flushes larvae)
  • Climate change → shifting transmission zones in SEA

CEH relevance:
Linking CMIP6 climate projections to future malaria risk windows

Risk Index = f(T, P, Cases)

Temperature layer (WorldClim)
        ↓ Gaussian suitability
    Temp suitability [0–1]
        ↓
Precipitation layer (WorldClim)
        ↓ Threshold function
    Rain suitability [0–1]
        ↓
  Composite Risk Index
  w₁·T_suit + w₂·P_suit
        ↓
  Overlay with case data
        ↓
  Risk map (ggplot2 + terra)

Temperature Suitability Function

# R/risk_index.R

#' Gaussian temperature suitability for Anopheles
#' Optimal at 25°C, zero outside 16-34°C (Mordecai et al. 2013)
temp_suitability <- function(temp_raster) {
  suit <- exp(-0.5 * ((temp_raster - 25) / 4)^2)
  suit[temp_raster < 16 | temp_raster > 34] <- 0
  return(suit / max(terra::values(suit), na.rm = TRUE))  # normalise 0-1
}

#' Rainfall suitability — breeding site availability
#' Optimal 150-300mm/month; zero below 50, above 400
rain_suitability <- function(rain_raster) {
  suit <- rain_raster
  suit[rain_raster < 50]  <- 0
  suit[rain_raster > 400] <- 0
  suit <- (suit - 50) / (300 - 50)
  suit[suit < 0] <- 0; suit[suit > 1] <- 1
  return(suit)
}

#' Weighted composite risk index
compute_risk_index <- function(temp_suit, rain_suit,
                                w_temp = 0.5, w_rain = 0.5) {
  return((w_temp * temp_suit) + (w_rain * rain_suit))
}

Running the Model

library(terra); library(sf); library(geodata)
source("R/risk_index.R")

# Load spatial layers
mys       <- gadm("MYS", level = 1, path = "data/raw/")
tmean_ann <- mean(worldclim_country("MYS", "tavg", "data/raw/"))
prec_ann  <- sum(worldclim_country("MYS", "prec",  "data/raw/")) / 12

# Apply suitability functions
temp_suit <- mask(crop(temp_suitability(tmean_ann), mys), mys)
rain_suit <- mask(crop(rain_suitability(prec_ann),  mys), mys)
risk      <- compute_risk_index(temp_suit, rain_suit)

# Join with case data
mys_sf <- sf::st_as_sf(mys) |>
  dplyr::left_join(cases, by = "NAME_1") |>
  dplyr::mutate(incidence = (cases / population) * 1000)

The Output: Dual Risk Map

library(tidyterra); library(patchwork)

p1 <- ggplot() +
  geom_spatraster(data = risk) +
  geom_sf(data = mys_sf, fill = NA, colour = "white", linewidth = 0.3) +
  scale_fill_distiller(palette = "YlOrRd", direction = 1,
                       name = "Climate\nRisk Index") +
  labs(title = "Climate Suitability",
       subtitle = "Temperature + Rainfall composite") +
  theme_void()

p2 <- ggplot(mys_sf) +
  geom_sf(aes(fill = incidence), colour = "white", linewidth = 0.3) +
  scale_fill_distiller(palette = "Reds", direction = 1,
                       name = "Incidence\n(per 1,000)") +
  labs(title = "Reported Malaria Incidence",
       subtitle = "Cases per 1,000 population") +
  theme_void()

p1 + p2   # patchwork side-by-side

are where the epidemiological conversation begins.

BLOCK 6

Quarto: Reproducible Report

One .qmd File — Everything in One Place

---
title: "Climate-Driven Malaria Risk Index — Malaysia"
author: "CEH Unit, NUS"
date: today
format:
  html:
    theme: cosmo
    code-fold: true     # code visible but collapsed by default
    toc: true
    fig-width: 12
    fig-height: 6
execute:
  echo: true
  warning: false
---

Why this matters for spatial epi:

  • Methods and maps cannot drift apart — same file
  • code-fold: true → clean for stakeholders, transparent for reviewers
  • date: today → always shows when analysis was run
  • Render to HTML, PDF, or Word by changing one line
quarto::quarto_render("report.qmd")
